# React useReducer Demo

A modern React application demonstrating state management using the **useReducer** hook, combined with a clean user interface and smooth micro-interactions.

**Live Demo:** https://bakadja.github.io/react-usereducer-demo/

---

## 🚀 About

This project showcases how to manage component state using React’s `useReducer` hook instead of `useState`.

Key points:
- Predictable state updates
- Reducer/action pattern
- Clean UI and micro-interactions

Features:
- Update the displayed name dynamically
- Increment age with a button

---

## 🧠 Why useReducer?

`useReducer` is useful when:
- state logic becomes more complex
- multiple state values depend on each other
- you want a predictable update flow (like Redux-style)
